## Typography & voice

- [x] Three type voices: Baloo2 (brand/display), `system-ui` sans (reading), `ui-monospace` (machine/metadata) — v3
- [x] Fixed reading size: 20px / 1.75 line-height, no responsive scaling (`--text-read`) — v2, bumped in v2.1
- [x] Reading measure: 42rem (`--spacing-read`); note width 36rem; images/embeds span `min(70rem, 95vw)` — v2 (40rem), widened in v3
- [x] Ragged-right body text (justify + hyphenation removed per feedback) — v2.1/v3
- [x] Drop cap on every article's first paragraph — v2 (serif), re-imagined in v3 as inverted terminal cursor block (mono glyph on `blue-950`)
- [x] Lowercase section headings, terminal aesthetic — v3
- [x] `strong` = `font-semibold` (not heavy black) — v1
- [x] `::selection` in brand blue; `:focus-visible` outline for keyboard users — v1/v3
- [x] One heading rule: all headings `blue-950`, single weight ramp, `font-extrabold` eliminated — v1
